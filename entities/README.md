# Entities

Esta é a pasta principal para montar as fases. Arraste os arquivos `.tscn`
para uma cena dentro de `scene`.

- `player`: personagem jogável.
- `enemies`: inimigos que podem causar dano.
- `creatures`: criaturas de cenário sem dano ao jogador.
- `npcs`: personagens preparados para interação e diálogo.
- `gameplay`: checkpoint, câmera, plataformas, blocos e fim de fase.
- `projectiles`: projéteis compartilhados pelos inimigos.

Os scripts ficam separados em `scripts` para que esta pasta mostre
principalmente aquilo que pode ser colocado diretamente no cenário.
