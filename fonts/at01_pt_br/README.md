# at01 PT-BR

Esta é uma variante da fonte pixel **at01**, de GrafxKid, criada para o
Peakguin. Os glifos latinos que eram apenas quadrados na fonte original foram
redesenhados no mesmo grid de 64 unidades para dar suporte real aos caracteres
acentuados usados em português.

A fonte original foi disponibilizada em domínio público sob **CC0 1.0**:

- <https://grafxkid.itch.io/at01>
- <https://creativecommons.org/publicdomain/zero/1.0/>

O arquivo `at01.ttf` original permanece em `res://fonts/at01.ttf`. A variante
gerada fica em `res://fonts/at01_pt_br/at01_pt_br.ttf`.

Para reconstruir a variante, instale o pacote Python `fonttools` e execute:

```text
python tools/fonts/build_at01_pt_br.py
```
